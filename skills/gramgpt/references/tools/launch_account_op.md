# launch_account_op

Run a bulk account operation: check, check_spamblock, reauthorize, generate_profiles, appeal_spamblock, set_2fa, reset_sessions (needs confirm: true), privacy, leave_chats, create_channels (a personal channel on each account, public and pinned by default). generate_profiles, create_channels and similar operations skip accounts busy with another task and run on the rest: see `skipped_accounts` and `account_results[].busy_with` in the task result. If every account is busy, the task fails with `account_overlap`.

## Input

| field | type | | notes |
|---|---|---|---|
| `op` | `appeal_spamblock` \| `archive_channels` \| `check` \| `check_spamblock` \| `copy_stories` \| `create_channels` \| `create_folder` \| `delete_private_chats` \| `generate_profiles` \| `leave_chats` \| `privacy` \| `reauthorize` \| `reset_sessions` \| `set_2fa` \| `unpin_folders` \| `unpin_personal_channel` | **required** | Which operation to run. |
| `account_ids` | integer[] | **required** | Accounts to operate on. Must belong to the caller.; min items `1` |
| `max_concurrent` | integer |  | Accounts processed at once (worker default if omitted).; min `1` |
| `tags` | string[] |  | Your labels for the task; filter with GET /tasks/?tag=.; max items `20` |
| `external_id` | string |  | Your own id for the task; filter with GET /tasks/?external_id=.; max len `128` |
| `confirm` | boolean |  | Required (true) for reset_sessions. WARNING: on fresh accounts imported from tdata, terminating the other sessions kills our own session too (measured: ~12% of such accounts died with 1-2 foreign sessions present). |

## config

Operation config. generate_profiles takes the same keys as the panel: settings, generate_name, generate_photo, photo_source, photo_category, photo_gender, omit_last_name, safe_mode, apply_to_telegram, generation_prompt, generate_username, keep_previous_photo (default true: a new avatar goes on top, previous ones stay; false deletes ALL previous ones). To set EXACT usernames pass username_pool: ["name1", "name2"] — handed out to account_ids in order, one each. Names and bios take the same pools: name_pool: [{"first_name": "...", "last_name": "..."}] (or custom_first_name/custom_last_name for all), bio_pool: ["..."] (or custom_bio for all). Own avatars: photo_source: "upload" + generate_photo: true + custom_photo_pool_base64: ["data:image/jpeg;base64,..."] (custom_photo_base64 for a single one). Or use the photo library with photo_source: "library" + photo_category / photo_gender. Pool order is sequential for usernames and bios, random for names and photos — pass <pool>_distribution: "sequential" to change it. per_account_plan: {"<account_id>": {"name_override": {"first_name": "...", "last_name": "..."}, "bio_override": "..."}} still works for explicit per-account values. appeal_spamblock REQUIRES appeal_text (30..2000 chars) — the free-form text @SpamBot's supervisor reads. The check ops need nothing. set_2fa: {password (>= 8 chars) \| auto_generate: true (unique password per account, returned ONCE in generated_passwords), hint, current_password} — with current_password it CHANGES an existing password, without it sets one on accounts that have none (others are skipped). privacy: {settings: {"last_seen" \| "phone_number" \| "profile_photo" \| "forwards" \| "calls" \| "groups" \| "voice_messages" \| "about" \| "birthday": "everyone" \| "contacts_only" \| "nobody", "mute_notifications": "on" \| "off"}}. leave_chats: {leave_type: "groups" \| "channels" \| "folders", delay_min, delay_max (seconds between leaves)} — leaves ALL chats of that type, not only the ones joined by tasks. reset_sessions needs no config but top-level confirm: true. set_2fa change: true without current_password changes the password using each account's saved one (accounts without it are skipped). delete_private_chats: {revoke (also for the other side — needs confirm: true), delay_min, delay_max}. archive_channels: {archive (default true; false returns them from the archive), channels (only these links, max 1000; empty = all channels and groups), include_bots, delay_min, delay_max} — private chats are never touched. unpin_folders: {delete_shared_links (default false keeps folders with your own invite link), folder_ids (one account only: only these folder ids from list_folders, own-link folders included; others stay), delay_min, delay_max} — chats stay. unpin_personal_channel needs no config. create_folder: {folder_name (<= 12 chars), mode: all \| selected, filter_type: all \| channels \| groups (mode=all), dialog_ids (mode=selected), folder_append (folder with this name exists: add the chats to it instead of replacing them)}. copy_stories: {source (@username, t.me link or account:<your account id>), story_ids (ids from get_stories), pin_to_top (default true), delete_existing, safe_mode (default on: one account at a time with pauses), skip_fresh_accounts}. create_channels: {channel_title (or channel_title_pool: [...] — one variant per channel, <= 128 chars), channel_about / channel_about_pool (<= 255), first_post_text / first_post_text_pool (<= 4096), text_distribution: random \| sequential, spintax {a\|b} works inside every text; pin_to_profile (default true), is_private (default false; a private channel can't be pinned), username: auto from username_topic (comma-separated) or the title when nothing is given, channel_username_pool: ["name1", ...] — exact usernames in account_ids order (extra names beyond the account count are spares: a taken or invalid username takes the next one), or channel_username: base(s), one per line + username_suffix: number \| random \| none; without spares a taken username is retried with a short tail up to 2 times; channel_photo_pool_base64: ["data:image/jpeg;base64,..."] (or channel_photo_base64) + photo_distribution, first_post_buttons, disable_reactions, allowed_reactions (emoji list, only these reactions in the channel; empty = all), pin_first_post, safe_mode (default on)}. First-post media is panel-only. Per-channel results (username, invite_link, pinned) are in /api/v1/tasks/{id}/.
